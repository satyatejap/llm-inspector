LLM call inspector

How to read this page

Each column is one LLM call, left to right in the order they happened. Each box in a column is one part of the prompt (tool schemas, system prompt, messages), top to bottom, sized by token count.

The coloured strip on the left of each box

  • Green – tokens read from the prompt cache (cheap, fast).
  • Amber – tokens written to the cache for the first time (slightly pricier).
  • Grey – not cached, billed at the normal input price.

Dashed lines

  • new in this call – everything above is identical to the previous call, so the cache can reuse it.
  • history changed here – the prompt differs from the previous call at this point, so everything below can't be served from cache.

Keyboard

  • / filter runs · ← → previous / next call while a box is open · Esc close panel · ? this help
